# Change: 轻量级 IDE 互动伙伴

## Why

当前 IDE（Claude Code、Cursor、Antigravity 等）虽然功能强大，但存在以下问题：
1. **进度不透明**：执行长时间任务（构建、测试、AI 分析）时，终端输出复杂难懂，开发者不知道进度
2. **错误信息复杂**：Stack trace 和技术错误对新手不友好
3. **缺乏趣味性**：冷冰冰的命令行界面，没有情感反馈
4. **无实时互动**：无法简单地"允许"或"取消"操作，需要手动输入命令

桌宠的优势：
- ✅ **轻量级**：不做代码分析等重型任务，专注于简化展示
- ✅ **零 Token**：核心功能使用规则引擎，不调用 AI API（省钱）
- ✅ **有趣味**：通过动画和可爱的交互方式提供反馈
- ✅ **填补空白**：做 IDE 懒得做的事情（进度提示、错误翻译、确认操作）

## What Changes

### MVP 功能（第一阶段）
1. **IDE 状态监听**
   - 监听 `~/.claude-code/status.json` 文件变化（或其他 IDE 的状态文件）
   - 解析 IDE 当前正在执行的任务、进度、消息

2. **实时进度显示**
   - 构建进度："构建中...60%"
   - 测试进度："测试中...12/45 通过"
   - AI 任务："Claude 正在分析代码..."

3. **错误简化翻译**（5 条核心规则）
   - 文件未找到："找不到 config.json 文件喵~"
   - 端口占用："3000 端口被占用了"
   - 数据库连接失败："数据库连接不上，检查配置"
   - 依赖缺失："缺少 express 包"
   - 权限错误："权限不够，可能需要 sudo"

4. **点击小猫 = 跳跃 = 允许操作**
   - IDE 请求确认危险操作时，桌宠显示确认气泡
   - 用户点击小猫 → 小猫跳跃动画 → 写入允许信号
   - IDE 读取信号后继续执行

5. **短期会话记忆**
   - 记住当前任务名称和开始时间
   - 记住最近 50 条 IDE 事件
   - 支持查询"现在在做什么？"

### 未来扩展（不在 MVP 中）
- 项目持久化记忆
- 开发习惯提醒（commit、休息）
- 进度可视化（小猫走路）
- 双向控制（取消、重试）

## Impact

### 新增功能模块
- **ide-companion**: IDE 集成核心功能
- **event-parser**: 事件解析和规则引擎
- **session-memory**: 会话记忆系统

### 影响的现有代码
- `ContentView.swift`: 添加 IDE 事件监听
- `ChatBubbleView.swift`: 可能需要支持新的气泡样式（确认操作）
- 新增文件：
  - `IDEMonitor.swift`: 文件监听和事件解析
  - `EventParser.swift`: 规则引擎
  - `SessionMemory.swift`: 会话记忆管理
  - `IDECommandWriter.swift`: 写入命令信号

### 外部依赖
- 需要 IDE 写入状态文件（提供示例 Hook 脚本）
- 使用 macOS `FSEvents` API 监听文件变化

### 用户体验变化
- 桌宠会主动显示 IDE 进度信息
- 新增交互方式：点击小猫确认操作
- 气泡内容更丰富（不仅是 AI 对话）
