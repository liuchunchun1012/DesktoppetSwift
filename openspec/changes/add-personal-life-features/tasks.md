## 验收标准

- [ ] 可以通过菜单或快捷键开始/暂停/停止
- [ ] 工作和休息时小猫动画正确切换
- [ ] 结束时有音效和通知
- [ ] 统计数据准确（今日/本周/总计）
- [ ] 数据同步到 iCloud

### 习惯提醒
- [ ] 喝水提醒按时触发
- [ ] 久坐提醒基于实际活动
- [ ] 眼睛休息提醒准确
- [ ] 可以在设置中禁用单个提醒
- [ ] 确认记录同步到 iCloud

### 语音交互
- [ ] Cmd+Shift+V 可以录音
- [ ] 录音转文字准确度 > 80%（中文）
- [ ] 本地命令正确识别和执行
- [ ] 未匹配命令正确降级到 AI
- [ ] TTS 在开启时正常播报

### 性能
- [ ] 内存占用 < 50 MB
- [ ] CPU 平均使用 < 1%
- [ ] 启动时间 < 2 秒
- [ ] 无明显卡顿或延迟

- [ ] 数据实时同步到 iCloud
- [ ] 多设备数据一致
- [ ] 离线时仍可使用本地功能
- [ ] 网络恢复后自动同步
