## Context
扩展设置界面，让用户可以在 GUI 中配置所有应用设置，无需修改代码。

**约束**:
- 设置变更需立即生效
- 精灵图支持用户自定义路径
- API Key 使用 Keychain 安全存储，其他设置用 UserDefaults

## Goals / Non-Goals
**Goals**:
- 统一的设置界面，包含 AI、外观、语言等配置
- 支持 OpenAI、Claude、Gemini、Qwen 等主流 API
- 支持用户自定义精灵图和翻译语言
- Ollama 可选安装，提供推荐模型列表

**Non-Goals**:
- 不做精灵图编辑器
- 暂不支持自定义快捷键
- 暂不做云端配置同步

## Decisions

### 设置界面使用 Tab 分组
**原因**: 设置项较多，分组更清晰。
```
┌─────────────────────────────────────┐
│ [AI 设置] [外观] [语言] [关于]      │
├─────────────────────────────────────┤
│                                     │
│  提供商: [Ollama ▼]                │
│  模型:   [gemma3:12b-it-qat ▼]     │
│  API Key: [••••••••] [测试]        │
│                                     │
│        [保存]  [取消]              │
└─────────────────────────────────────┘
```

### Ollama 推荐模型列表
安装脚本提供以下推荐模型供用户选择：
| 模型 | 大小 | 特点 |
|------|------|------|
| `gemma3:4b-it-qat` | ~3GB | 轻量通用，QAT 优化 |
| `gemma3:12b-it-qat` | ~8GB | 均衡性能 |
| `qwen3:4b` | ~3GB | 中文优化 |
| `llava:7b` | ~5GB | 支持视觉 |

### 使用 UserDefaults 存储非敏感配置
**原因**: 简单高效，macOS 原生支持。
- 精灵图路径 → UserDefaults
- 翻译语言 → UserDefaults
- 当前提供商 → UserDefaults
- API Key → Keychain

## Risks / Trade-offs
- **精灵图格式兼容** → 只支持 PNG，要求用户按标准目录结构组织
- **Ollama 模型较大** → 安装脚本提示用户磁盘空间需求

- 是否需要支持导入 GIF 动图作为精灵？
