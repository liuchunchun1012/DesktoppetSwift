# 照片转桌宠精灵 - 使用指南 📸

## 概述

这是一个全新的简化工作流，让你只需**上传一张猫咪照片**，AI 自动生成完整的 74 帧桌宠动画！

## 快速开始

### 1. 启动编辑器

```bash
cd sprite-editor
./start-editor.sh
```

浏览器会自动打开：`http://localhost:8888/photo-to-sprite.html`

### 2. 准备照片

**推荐的照片要求：**
- ✅ 清晰的猫咪正面照
- ✅ 背景简单（纯色最佳）
- ✅ 猫咪占据画面中心
- ✅ 光线充足，特征清晰

**不推荐：**
- ❌ 模糊、侧面、背面照片
- ❌ 背景复杂（难以去除）
- ❌ 猫咪太小或太远
- ❌ 光线暗淡

### 3. 上传并生成

1. **输入 Gemini API Key**（首次使用）
2. **上传照片**：拖拽或点击按钮
3. **预览**：查看自动生成的像素风预览
4. **点击"生成完整桌宠动画"**
5. **等待 5-10 分钟**（AI 生成 74 帧）
6. **下载 ZIP 文件**

### 4. 导入桌宠

1. 解压下载的 ZIP 文件
2. 打开桌宠应用
3. 设置 → 自定义精灵
4. 选择解压后的文件夹
5. 完成！

## 工作原理

### 第一步：照片像素化

系统会自动将你的照片转换为 128x128 的像素风格：
- 裁剪为正方形（保持宽高比）
- 颜色量化（简化到 8 级颜色）
- 自动去背景（基于亮度阈值）

### 第二步：AI 生成动画

AI 会：
1. 分析照片中猫咪的外观特征（毛色、花纹、眼睛等）
2. 读取官方动作模版（74 个不同姿态）
3. 将猫咪的外观应用到每个动作帧
4. 智能推断不同视角（正面 → 背面/左侧/右侧）

### 官方动作模版包含：

| 动作类型 | 帧数 | 说明 |
|---------|------|------|
| eating（吃东西） | 7帧 | 可爱的进食动画 |
| grooming 1-12（理毛） | 12帧 | 舔爪子理毛 |
| idle（待机） | 12帧 | 静止站立 |
| sleeping 1-3（睡觉） | 3组 | 不同睡姿 |
| walk/down（向下走） | 6帧 | 正面行走 |
| walk/up（向上走） | 6帧 | 背面行走 |
| walk/left（向左走） | 6帧 | 左侧行走 |
| walk/right（向右走） | 6帧 | 右侧行走 |
| yawn（打哈欠） | 7帧 | 打哈欠伸懒腰 |

**总计：74 帧完整动画**

| **适用场景** | 🟢 快速生成自己猫咪的桌宠 | 🟢 创作虚拟/想象中的宠物 |

## 常见问题

### Q: AI 生成需要多久？

A: 约 5-10 分钟。系统需要生成 74 帧动画，每帧都需要 AI 处理。

### Q: 生成失败怎么办？

A: 可能原因：
1. **API Key 无效** - 检查是否正确输入
2. **API 限流** - 稍后重试
3. **照片质量** - 尝试换一张更清晰的照片
4. **网络问题** - 检查网络连接

### Q: 生成的动画不满意？

A: 可以尝试：
1. 换一张角度更好的照片
2. 使用背景更简单的照片
3. 调整照片的亮度/对比度后再上传
4. 如果需要完全自定义，使用手绘模式（`editor.html`）

### Q: 可以上传其他动物的照片吗？

A: 理论上可以，但效果可能不佳，因为：
- 官方动作模版是为猫咪设计的
- AI 的 prompt 针对猫咪优化
- 建议只用于猫咪照片

### Q: 照片会被上传到服务器吗？

A: **不会！**所有处理都在浏览器本地完成：
- 照片只发送给 Gemini API 进行 AI 生成
- 不会上传到我们的服务器
- Gemini API 调用后不保留你的数据

### Q: 需要什么样的 Gemini API Key？

A: 你需要：
1. 访问 [Google AI Studio](https://makersuite.google.com/app/apikey)
2. 创建免费的 API Key
3. 免费额度足够生成多个桌宠动画

### Q: 生成的 ZIP 文件如何使用？

A:
1. 解压 ZIP 文件
2. 你会看到类似这样的目录结构：
   ```
   my-pet-sprite-xxxxx/
   ├── eating/
   │   ├── frame_01.png
   │   ├── frame_02.png
   │   └── ...
   ├── walk/
   │   ├── down/
   │   ├── up/
   │   ├── left/
   │   └── right/
   └── ...
   ```
3. 在桌宠应用中选择这个文件夹即可

## 技术细节

### 照片预处理

```javascript
// 1. 裁剪为正方形
const size = Math.min(img.width, img.height);
const offsetX = (img.width - size) / 2;
const offsetY = (img.height - size) / 2;

// 2. 缩放到 128x128
ctx.drawImage(img, offsetX, offsetY, size, size, 0, 0, 128, 128);

// 3. 颜色量化（8 级）
r = Math.round(r / 32) * 32;
g = Math.round(g / 32) * 32;
b = Math.round(b / 32) * 32;

// 4. 背景去除（亮度阈值）
if (brightness > 240 || brightness < 15) {
    alpha = 0; // 透明
}
```

### AI 提示词结构

```
任务：照片 → 像素风动画帧

输入：
- 用户照片（已像素化）
- 官方动作模版帧

输出：
- 保持模版的动作姿态
- 应用照片的外观特征
- 智能推断不同视角
- 128x128 PNG，透明背景
```
