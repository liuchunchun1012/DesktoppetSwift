# 像素画编辑器使用指南 🎨

## 更新说明

根据你的反馈，编辑器已从"自由绘画"模式改为**像素块填色**模式！

### 新的编辑方式

✨ **像素块填色**：类似 Minecraft 皮肤编辑器
- 点击格子 → 填上颜色
- 按住鼠标拖动 → 连续填色
- 每个像素都精准控制

## 快速开始

### 1. 启动编辑器

```bash
cd sprite-editor
./start-editor.sh
```

浏览器会自动打开：`http://localhost:8888`

### 2. 开始填色

#### 步骤 A：选择颜色

在页面下方的"选择颜色"区域：
- 点击预设颜色按钮
- 或使用自定义颜色选择器

当前颜色会显示在"当前颜色："后面。

#### 步骤 B：填色

1. 选好颜色后
2. 在 4 个视角的画布上**点击像素格子**
3. 格子会被填上你选择的颜色

**技巧**：
- 单击 = 填一个格子
- 按住鼠标拖动 = 连续填色（像画笔）

#### 步骤 C：擦除

点击"🧹 橡皮擦（透明）"按钮
- 然后点击要擦除的格子
- 格子会变为透明

### 3. 加载参考图（可选）

如果你有现成的图片想要参考：

1. 点击"📁 加载参考图"
2. 选择图片文件
3. 图片会以半透明形式显示在画布上
4. 你可以对着参考图填色

### 4. 生成动画

1. 输入 Gemini API Key 并保存
2. 点击"🚀 生成精灵动画"
3. 等待 5-10 分钟
4. 完成后会显示在"生成历史"

### 5. 下载 ZIP

1. 在"生成历史"选择版本
2. 点击"💾 下载 ZIP 文件"
3. 解压到本地
4. 在桌宠设置中选择该文件夹

## 网格线说明

编辑器会自动显示网格线：
- **细网格**：每 1 像素（半透明灰色）
- **粗网格**：每 8 像素（方便对齐）

这样你可以清楚地看到每个像素格子的位置。

## 常见问题

### Q: 点击填色没反应？

A:
1. 检查是否选择了颜色（看"当前颜色"显示）
2. 刷新页面重试
3. 打开浏览器控制台查看错误

### Q: 格子太小了，看不清？

A: 画布尺寸是 128x128 像素（实际精灵图尺寸），你可以：
- 放大浏览器页面（Cmd/Ctrl + "+"）
- 先加载参考图，对照着填色

### Q: 能否撤销操作？

A: 目前暂不支持撤销，但你可以：
- 用橡皮擦擦除错误的格子
- 点击"🗑️ 清空"重新开始

### Q: 如何填充大面积相同颜色？

A: 按住鼠标左键拖动即可连续填色（类似画笔）。

### Q: 参考图会影响最终生成吗？

A: 不会！参考图只是半透明显示，不会保存到最终图片中。
最终生成的精灵图只包含你手动填色的像素。

## 技巧和建议

### 1. 从简单开始

第一次使用建议：
- 先填纯色（例如纯黑色的猫）
- 测试生成流程
- 熟悉后再做复杂设计

### 2. 利用对称性

宠物通常左右对称：
- 填好左侧面 → 复制到右侧面
- 填好正面 → 参考填背面

### 3. 使用参考图

- 上传 nano banana 的原版图片
- 对照着改颜色
- 保持形状不变

### 4. 先勾轮廓，再填色

1. 用黑色勾出轮廓
2. 用其他颜色填充内部
3. 添加细节（眼睛、鼻子等）

### 5. 保存多个版本

- 每次生成都会保存为新版本
- 可以尝试不同配色方案
- 对比选择最佳效果

## 像素艺术资源

### 调色板推荐

- **纯色系**：
  - 黑白猫：黑色 #000000 + 白色 #ffffff
  - 橘猫：橙色 #ffa07a + 白色 #ffffff
  - 灰猫：灰色 #888888 + 白色 #ffffff

- **渐变系**：
  - 浅 → 深：使用 3-4 个相近颜色
  - 增加层次感
